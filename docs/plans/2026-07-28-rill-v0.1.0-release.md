# Rill v0.1.0 macOS ARM64 Release Implementation Plan

> **For Claude:** Use `${SUPERPOWERS_SKILLS_ROOT}/skills/collaboration/executing-plans/SKILL.md` to implement this plan task-by-task.

**Goal:** Build, verify, install, and publicly release Rill v0.1.0 for macOS ARM64 with reproducible assets, explicit ad-hoc-signing limitations, isolated first-run acceptance, and redacted evidence.

**Architecture:** Keep the existing Wails 2.12.0 application build and create-dmg packaging primitives, but add a Rill-only release wrapper and a least-privilege `rill-v*` GitHub workflow. The wrapper produces deterministic ARM64 CLI/DMG names and checksum sidecars; the workflow verifies the tag is on `main`, runs the release gates, builds on a native Apple Silicon runner, and publishes only the reviewed files. A clean-room acceptance uses isolated Rill home/state/cache directories so existing credentials, sessions, projects, and caches cannot make first-run validation pass accidentally.

**Tech Stack:** Go 1.26.5, Wails 2.12.0, Node.js 24, pnpm 10.34.5, Bash, create-dmg, codesign, Playwright, GitHub Actions, GitHub CLI.

---

## Fixed scope and release decisions

- Release only macOS ARM64 desktop and ARM64 CLI.
- Trigger only on annotated tags matching `rill-v*`.
- Publish `Rill-darwin-arm64.dmg`, `Rillagent-darwin-arm64.tar.gz`, and one `.sha256` sidecar for each archive.
- `Rill.app` is the application inside the DMG, not a standalone GitHub asset; GitHub cannot upload a directory directly.
- Use ad-hoc codesign only. Do not claim Developer ID signing, notarization, Gatekeeper trust, or App Store compatibility.
- Keep the existing credential contract for v0.1.0: provider values are stored in the restricted Rill home `.env`, not macOS Keychain. Disclose this in README and release notes.
- Do not reuse upstream mirrors, domains, update manifests, signing keys, npm, Homebrew, Windows, Linux, or website workflows.
- Do not merge, tag, or publish until the preceding code, local package, clean-room, and exact-HEAD CI gates are green.
