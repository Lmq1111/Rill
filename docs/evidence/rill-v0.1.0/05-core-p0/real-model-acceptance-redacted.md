## 上下文边界观察

1. 清空后、重启前，历史仍完整显示。
2. 重启后，上下文概览显示“模型上下文已清空；历史消息仍完整保留”，占用为 `0 k / 1000 k`。
3. 在不使用工具、不读取文件的条件下发送边界探针。
4. 模型只返回 `context-boundary-ok`，没有返回清空前的合成记忆标记。
5. 新一轮完成后，上下文占用只反映清空后的新请求，旧历史仍在原会话中可查看。
